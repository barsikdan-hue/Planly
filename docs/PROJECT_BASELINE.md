# Planly — единый baseline проекта

Дата проверки: 30 сентября 2026.

## Основная версия

Ветка `main`: светлый Personal SMM Planner, выбранный владельцем.
Сайт: https://personal-smm-planner.barsikdan.chatgpt.site
Источник Sites: `appgprj_6abcf59110348191b18115ba3fd6e410`
Исходный commit: `5cf252b3d5600a46015f2b310c8f0ae4134fdf05`
Импорт: 131 отслеживаемый файл, включая lockfile и конфигурацию Sites.

React 19, TypeScript, Next.js API через Vinext/Vite; Tailwind и UI-компоненты.
Экраны: Dashboard, Create Post, Calendar, Content, Media, Social Accounts,
Settings и демонстрационная Analytics.
Сохранение: IndexedDB в конкретном браузере.
Отправка постов, AI, аналитика и подключённые аккаунты в этой версии демонстрационные.
Рабочая PostgreSQL, production auth, BullMQ/Redis и Docker отсутствуют.
CURRENT PHASE: UI PROTOTYPE (Phase 1), production foundation (Phase 0) не завершён.

## Сохранённая ранняя версия

Ветка `reference/dark-mvp`: отдельный полный снимок раннего тёмного сайта.
Сайт: https://personal-smm-planner-danil-0920.barsikdan.chatgpt.site
Источник Sites: `appgprj_6aafa399d06c81919f54102542dabd6e`
Исходный commit: `e6153a343cd2dc9f9417cce1838ee0c7aa4d0c96`
Импорт: 120 отслеживаемых файлов.

Имеются server/api.mjs, server/social.mjs, server/worker.mjs, серверная
валидация, отдельные доставки, защита по владельцу, шифрование токенов,
Cloudflare D1/R2 и локальное SQLite-хранилище. Эта реализация отличается
от запланированных PostgreSQL и Redis/BullMQ и не перенесена в светлый UI.
В Sites не настроен независимый фоновый cron; отправка с реальными
токенами не подтверждена. Сохраняем как источник проверяемых решений,
не сливаем её дерево файлов целиком в main.

## Единый рабочий процесс

1. GitHub Planly/main — основной источник кода для будущей разработки.
2. Sites — действующий светлый прототип и отдельная прежняя версия.
3. Изменения в GitHub не публикуются в Sites автоматически. Перед публикацией
   нужно перенести выбранный проверенный commit в исходный репозиторий
   существующего Sites-проекта и выполнить обычный workflow Sites.
4. Доступ к сайтам не изменён. В GitHub находится только код.
5. Браузерные IndexedDB, D1/R2-данные и secrets не импортируются в GitHub.
6. Figma-файл к репозиторию пока не привязан; подключение плагина не
   создаёт дизайн-эталон автоматически.
7. Render для Planly пока не проверен и не настроен; не переносить текущий
   Cloudflare Worker в Render без адаптации runtime и авторизации.
