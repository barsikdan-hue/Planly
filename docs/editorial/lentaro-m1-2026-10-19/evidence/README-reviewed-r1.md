Общий профиль Telegram/MAX: 500–1024 UTF-16, JPEG; совместимость с актуальным provider transport проверяется отдельно при загрузке. В текст включено происхождение изображения. Заголовок уже входит в `text`; при отправке его повторно добавлять не нужно.

В `assets/originals/` сохранены 3 настоящих исходных PNG из встроенного imagegen. В `assets/final/` — 12 производных JPEG: для каждого материала portrait 1080×1350, square 1080×1080, mobile 270×338 и 360×450. В API выбирается ровно один portrait; square/mobile — варианты и QA-превью, не альбом из повторяющихся изображений. Экспорт сохраняет весь кадр, квадрат имеет боковые поля, важные объекты не срезаны. На обложках нет заголовков, AI-ярлыков, логотипов и водяных знаков. Правило 72 px для значимых надписей неприменимо: надписей нет. Это сознательное визуальное решение; весь смысл и ограничения доступны в тексте.

`input-snapshot.json` содержит точные тексты, упорядоченные primary assets, варианты, hashes, prompt и контекст размещения. `snapshot-digest.json` хранит SHA отдельно. `review-context.json` фиксирует hashes источников, claims, расчётов и API mapping. Независимые отчёты должны ссылаться на snapshot SHA и reviewed asset hashes. Изменение текста, подписи, медиа или существенного контекста требует новой ревизии; старое review не переносится.
