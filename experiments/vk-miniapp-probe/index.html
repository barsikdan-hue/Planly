Проверяем разрешения для новых фотографий

Сначала VK запросит ваше согласие на wall, photos и groups. Список управляемых сообществ используется только для проверки тестовой группы и не показывается, не сохраняется и не передаётся на сервер Planly. Затем можно проверить доступ к методу загрузки. Первые две кнопки ничего не публикуют и не загружают. Отдельная третья кнопка ниже запускает одну разрешённую тестовую публикацию.

Срок действия пока неизвестен.

Токен не показывается, не сохраняется в браузерное хранилище и не отправляется на сервер Planly. «Очистить результат» очищает сохранённый токен страницы; уже начатый запрос VK может завершиться. Это не отзывает разрешение в VK. Диагностика не подключает планировщик.

Проверка результата без отправки

Один запрос читает последние пять постов только тестовой группы. Отображаются лишь статус совпадения и ссылка на совпавший пост. Отсутствие совпадения не снимает запрет повторной отправки. Этап прошлой попытки восстановить нельзя.

Диагностика: только загрузка файла

Отдельный однократный тест загрузит эту же нейтральную PNG-картинку в VK. Сохранение фото и создание поста не выполняются. Маркер прошлой публикации сохраняется. Результат загрузки может оказаться неподтверждённым — повторять нельзя.

Тест: загрузка через сервер Planly

Только после отдельного разрешения владельца: временный адрес загрузчика и PNG передаются серверу Planly. Токен VK не передаётся. Нужна действующая сессия владельца Planly; если браузер не передаёт её из iframe, тест не допускается. Сервер выполняет одну загрузку без сохранения фото и без поста. Старые маркеры сохраняются.

Одна тестовая публикация

Группа: №242095689. Новая тестовая картинка создаётся здесь, без внешних сервисов.

Нажатие кнопки загрузит файл в VK, сохранит фото и создаст один пост. После начала операции повтор заблокирован, в том числе после очистки результата или перезагрузки. При ошибке или неизвестном исходе не повторяйте отправку.
