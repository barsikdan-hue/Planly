# Planly — Personal SMM Planner MVP

Личный планировщик с тёмным интерфейсом, серверной базой, приватной медиатекой и адаптерами Telegram, VK, Instagram. Новое пространство пустое: вымышленные аккаунты и охваты не создаются.

## Запуск

Нужен Node.js 24 LTS (встроенный node:sqlite).

```sh
npm ci
npm run build
npm start
```

Откройте http://127.0.0.1:5173. Если готовая dist включена в архив, достаточно npm start: сервер запускается без внешних пакетов.

Локальный вход создаёт сессию устройства без обращения к ChatGPT и предназначен только для разработки. Сервер слушает 127.0.0.1 и проверяет Host. Не выставляйте его в интернет через прокси или туннель. В Sites вход и приватный доступ обеспечивает платформа, API требует подтверждённые ею заголовки пользователя.

Локальные данные: .data/planly.sqlite, .data/media, .data/token.key. Ключ необходим для расшифровки подключений. Для резервной копии остановите сервер и сохраните всю .data в защищённое место. Каталог исключён из Git и архива. PLANLY_DATA_DIR меняет каталог, PORT — порт.

## Возможности

- Dashboard с реальными счётчиками, неделей и быстрыми идеями.
- Создание, редактирование, копирование, удаление постов; черновики, выбор сетей, UTC-расписание с отображением в часовом поясе устройства.
- Календарь, поиск, фильтры и переключаемый предпросмотр.
- Приватная загрузка JPG, PNG, WebP, MP4 до 20 МБ.
- Проверка подключений через API. Токены шифруются AES-256-GCM и не возвращаются браузеру после сохранения.
- Журнал каждого направления и ID публикации. Статус «Опубликован» требует подтверждения всех выбранных сетей.
- Успешные направления не отправляются повторно. Потерянный ответ требует проверки канала перед ручным повтором.
- Проверка владельца, подготовленные SQL-запросы, защита записи от чужого origin, ревизии и уникальные маркеры операций.

## Подключения

Вводите токены только на экране «Соцсети», не в чате.

**Telegram:** бот от @BotFather, добавленный администратором канала с правом публикации. Токен и @имя либо ID канала. Текст до 4096 символов; JPG/PNG и MP4 с подписью до 1024 символов.

**VK:** токен с правом wall и доступом к сообществу, ID со знаком минус. В этой версии — текстовые посты. Окончательные права проверяет сама соцсеть при отправке.

**Instagram:** профессиональный аккаунт, токен Instagram Login с instagram_business_basic и instagram_business_content_publish. Одно фото по публичной HTTPS-ссылке на JPEG, подпись до 2200 символов. Прямая отправка из приватной медиатеки, OAuth-мастер, обновление токенов, Stories, Reels и карусели пока не реализованы.

Адаптеры проверены подменёнными ответами провайдеров. Сквозная отправка с реальными токенами требует проверки после подключения.

## Расписание

Локальный сервер проверяет очередь каждые 15 секунд. Браузер можно закрыть, но компьютер и сервер должны работать. После простоя просроченная очередь продолжает обрабатываться.

В текущем размещении Sites очередь проверяется каждые 15 секунд при открытом приложении. После закрытия отправка возобновится при следующем входе. Круглосуточный облачный cron пока не настроен; интерфейс прямо показывает это ограничение.

Worker экспортирует scheduled для настройки фонового триггера на поддерживающем его хостинге. SCHEDULER_MODE=cron меняет только надпись, а не создаёт триггер. Не устанавливайте это значение в облаке до проверки реального фонового запуска.

До 5 направлений за проход. Автоматических повторов нет. Незавершённая после сбоя отправка через 3 минуты становится неопределённой: сеть могла принять пост. Гарантии exactly-once для внешних API нет.

## Sites и архитектура

Существующий ID в .openai/hosting.json. Доступ приватный. D1 DB хранит данные, R2 BUCKET — файлы. TOKEN_KEY — секрет из 32 случайных байтов в Base64, управляется через Sites. Смена ключа без миграции делает сохранённые токены недоступными. Облачный режим: SCHEDULER_MODE=on-open.

MVP использует React, TypeScript, Tailwind/shadcn и собственный Cloudflare Worker API. Сохранён исходный Vinext/Next-compatible каркас, но рабочая сборка не использует Next.js сервер. Старые dev/build:framework относятся к каркасу; для MVP используйте build и start.

- server/api.mjs — API и очередь.
- server/social.mjs — адаптеры.
- server/crypto.mjs — шифрование.
- server/worker.mjs — облачный вход.
- server/local-store.mjs — локальные SQLite и файлы.
- db/schema.ts, drizzle — схема и миграции.
- components/planner.tsx, components/composer.tsx — интерфейс.
- app/globals.css — тёмная тема.

Сборка: dist/server/index.js. Метаданные и миграции: dist/.openai.

```sh
npm run typecheck
npm test
npm run test:mvp
npm run build
```

Удаление поста из Planly не удаляет опубликованный пост из соцсети. Восстановление удалённого через UI, AI, охваты, команды, биллинг и автопродление токенов в MVP не входят.
